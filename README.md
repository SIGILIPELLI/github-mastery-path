# GitHub & Git Mastery Path

A free, structured, module-wise Git version control and GitHub training program — entry level to master level, with real command walkthroughs in every module and a hands-on project at the end of each level.

**Live site:** https://sigilipelli.github.io/github-mastery-path/

## Contents

- **Level 1 · Entry** — Git fundamentals & GitHub basics
- **Level 2 · Intermediate** — collaboration: PRs, issues, releases
- **Level 3 · Advanced** — Git internals, history rewriting, CI
- **Level 4 · Master** — advanced Actions & team workflow design

## Local development

```bash
python3 -m venv .venv
.venv/bin/pip install mkdocs-material
.venv/bin/python -m mkdocs serve
```
